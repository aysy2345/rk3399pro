# 摄像头预览水平翻转设计

## 背景

当前 `VideoWidget` 按摄像头输入原样显示，没有软件镜像。用户的笔记本摄像头或驱动输出了镜像画面，因此主窗口和成员登记窗口中的方向与真实场景相反。

## 目标

- 将当前笔记本摄像头预览恢复为非镜像方向。
- 只改变显示，不改变检测、五点对齐、特征提取、登记或识别输入。
- 人脸框、姓名与相似度标签在翻转后继续准确覆盖对应人脸。
- 板端更换摄像头后可以通过配置关闭翻转。

## 配置

在 `camera` 段新增布尔字段：

    "preview_flip_horizontal": true

- `true`：显示前水平翻转，用于纠正当前镜像输入。
- `false`：按摄像头原始方向显示。

示例配置和当前本地配置均设为 `true`。配置加载器拒绝非布尔值。

## 显示层实现

`VideoWidget` 接受 `flip_horizontal` 构造参数：

1. `set_frame` 仍接收原始 BGR 帧，仅在转换为内部 QImage 前水平翻转显示副本。
2. `set_result` 保留模型返回的原始帧和原始检测框。
3. 绘制叠加框时，若启用翻转，将原始横坐标 `(x1, x2)` 映射为 `(width - x2, width - x1)`。
4. 纵坐标、识别结果、成员库和模型输入保持不变。

启动层把同一配置同时传给主窗口和登记向导，保证两个预览方向一致。

## 测试

- 配置测试覆盖缺省值、`true`、`false` 和非布尔值。
- 使用左右颜色不同的测试帧验证显示图像确实水平翻转。
- 使用偏左检测框验证翻转后绘制位置移动到右侧。
- 验证关闭配置时保持现有原始方向。
- 运行全部 Qt、配置、集成和完整回归测试。

## 非目标

- 不翻转摄像头采集帧本身。
- 不修改 ONNX 或未来 RKNN 推理输入。
- 不修改人脸特征库和识别阈值。
- 不增加旋转、裁剪或垂直翻转功能。
