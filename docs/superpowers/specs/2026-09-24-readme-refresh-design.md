# GitHub README 刷新设计

## 目标

更新根目录 README，使 GitHub 首页准确反映项目已经完成 ONNX 推理验证、当前处于 Phase 5，并让读者快速理解项目用途、现状、验证方式和最终上板路径。

## 修改范围

本次只修改根目录 README，不继续实现摄像头、界面、RKNN 转换或板端后端。

README 采用以下结构：

1. 项目简介：RK3399Pro、USB UVC 摄像头、50 人以内、离线 1:N 人脸识别和 PyQt5 成员管理。
2. 当前状态：Phase 1 至 Phase 4 完成，Phase 5 尚未开始；明确说明当前版本还不能直接在板端运行完整应用。
3. 已完成功能：配置、人脸库、对齐、质量检查、匹配、稳定器、登记聚合、Fake 后端、两个 ONNX 后端及一致性验证。
4. 模型信息：RetinaFace MobileNet0.25 和 MobileFaceNet 的输入、输出及模型文件不进入 Git 的说明。
5. 本机验证：提供测试、ONNX 导出和检查命令。
6. 上板路线：简述 Windows/开发机、Ubuntu 18.04 x86_64 转换机、RK3399Pro ARM64 三个环境及后续阶段。
7. 配置与文档：链接示例配置、设计、实施计划、任务进度和模型说明。

## 内容原则

- 不把“规划中的功能”写成“已经完成”。
- 不承诺尚未验证的 RKNN 性能、识别准确率或板端帧率。
- 根 README 保持概览性质，详细部署和实施步骤链接到已有文档。
- 所有命令与当前仓库文件路径一致。
- 明确 ONNX、RKNN、PTH 和人脸数据不会提交到普通 Git 历史。

## 验证

- 检查 README 中的相对链接目标存在。
- 运行完整单元测试。
- 执行 Git 差异检查，确认只修改 README 和本设计说明。
- 提交并推送后核对本地与远程 main 哈希一致。
