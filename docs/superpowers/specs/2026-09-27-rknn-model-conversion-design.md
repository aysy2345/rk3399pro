# RKNN 模型转换设计

## 1 目标

在可长期保留的 Ubuntu 18.04 x86_64 虚拟机中，将项目现有 RetinaFace MobileNet0.25 和 MobileFaceNet ONNX 模型转换为适用于 RK3399Pro 的 RKNN 模型，并用固定样本验证转换前后的检测和特征输出。

本阶段只负责转换环境、转换工具和模型一致性验证。板端摄像头接入、RKNN Lite 推理后端和性能调优属于后续阶段。

## 2 转换主机

使用 VMware 中的 Ubuntu 18.04.6 x86_64，保持与课程资料一致。宿主机有 16 GB 内存，虚拟机采用以下配置：

- 4 个虚拟 CPU 核心
- 6 GB 内存
- 40 GB 动态扩展磁盘
- NAT 网络
- 默认显示配置，不依赖 3D 加速

虚拟机内使用 Python 3.6.9 和 RKNN Toolkit 1.7.1。环境配置完成并通过工具导入测试后创建 VMware 快照。虚拟机不用时彻底关机，避免长期占用宿主机内存。

## 3 转换流程

两个模型分别使用独立入口脚本，共用参数校验、日志记录和输出文件命名逻辑。

转换顺序如下：

1. 检查 ONNX 模型、校准清单和输出目录。
2. 加载 ONNX 模型并配置目标平台 RK3399Pro。
3. 先构建非量化 RKNN 模型。
4. 导出模型并运行模拟器一致性验证。
5. 非量化模型通过后，再使用代表性图片清单构建 INT8 模型。
6. 比较模型大小、输出误差和特征相似度，决定板端默认模型。

非量化和 INT8 产物使用不同文件名，转换过程不覆盖已通过验证的模型。

## 4 输入与预处理

应用从 OpenCV 获取 BGR 图像，转换模型保持 BGR 通道顺序。

RetinaFace 输入尺寸为 640 × 640。RKNN 配置执行每通道减均值，均值为 `(104, 117, 123)`，不进行额外缩放。模型保留位置、分类和五点关键点三个输出，后处理继续复用项目现有 RetinaFace 解码逻辑。

MobileFaceNet 输入尺寸为 112 × 112。输入采用项目现有五点对齐结果，RKNN 配置执行 `(像素 - 127.5) / 127.5`。模型输出为 512 维特征，比较前执行 L2 归一化。

转换配置和验证程序使用同一份模型元数据，避免脚本与板端后端分别维护输入尺寸或预处理常量。

## 5 校准数据

INT8 校准清单只引用本地图片路径，不把图片复制进仓库。RetinaFace 使用包含正脸、侧脸、远近距离和常见室内光照的摄像头帧。MobileFaceNet 使用完成五点对齐的 112 × 112 人脸图像。

清单生成工具负责扩展名过滤、路径存在性检查、去重和固定随机种子抽样。仓库只提交清单格式示例，不提交真实人脸照片或生成后的本地清单。

## 6 一致性验证

验证工具对同一组固定图片分别运行 ONNX Runtime 和 RKNN Toolkit 模拟器，并输出机器可读结果与终端摘要。

RetinaFace 验证以下内容：

- 三个输出均存在，形状符合模型契约
- 检测到的人脸数量一致
- 匹配检测框的坐标误差处于配置容差内
- 五点关键点的坐标误差处于配置容差内

MobileFaceNet 验证以下内容：

- 输出维度为 512
- 输出不包含 NaN 或无穷值
- 非量化 RKNN 与 ONNX 特征余弦相似度不低于 0.99
- INT8 结果单独记录，不因达到可运行状态而自动成为默认模型

若 INT8 明显降低身份区分度，则 RetinaFace 和 MobileFaceNet 可以分别选择非量化或 INT8，不要求两个模型采用同一量化策略。

## 7 错误处理

脚本在 RKNN Toolkit 版本不符、输入文件缺失、校准清单为空、模型加载失败、构建失败或导出失败时立即停止并返回非零状态。

转换日志中的设备连接提示与模型构建错误分开处理。课程资料指出，无开发板连接时可能出现设备相关错误；脚本仍以 RKNN API 返回值、导出文件存在性和模拟器验证结果共同判断是否成功。不支持算子错误不能忽略。

如果 RetinaFace 无法稳定转换，只替换人脸检测模型。对齐、MobileFaceNet、成员存储和界面接口保持不变。

## 8 仓库变更范围

实现阶段新增以下内容：

- RetinaFace RKNN 转换入口
- MobileFaceNet RKNN 转换入口
- 共用转换配置和错误检查
- 校准清单生成工具
- ONNX 与 RKNN 输出对比工具
- Ubuntu 18.04 环境与执行说明
- 不依赖已安装 RKNN Toolkit 的单元测试

`.rknn` 文件、转换日志、校准图片、真实清单和虚拟机文件继续由 `.gitignore` 排除。

## 9 验收条件

- Ubuntu 18.04 虚拟机可重复安装指定版本环境。
- 两个转换入口能从现有 ONNX 文件生成非量化 RKNN 文件。
- 固定样本上的 RetinaFace 框和关键点通过一致性检查。
- MobileFaceNet 非量化特征余弦相似度不低于 0.99。
- INT8 结果包含模型大小和精度对比，默认模型选择有记录。
- 转换日志中没有未处理的不支持算子错误。
- 仓库中不包含模型产物、真实人脸图片或虚拟机文件。
